# SmartSample
College Student Analytics & Statistical Estimation Platform (Module VI: Sampling & Estimation).
React + TypeScript + Tailwind CSS + Recharts + Lucide. No backend; all data is simulated in the browser.

## Run locally (Node 18+)
    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

## Structure
- src/lib/stats.ts: population, sampling, statistics, experiment, generated text
- src/components/: Home, Analyze, Experiment, About, Shared
